# 人工冒烟测试清单

> 2026-08-13 版（统一表单与导航重构后）
> 每次代码变更后必跑，预计 25 分钟/轮

## 准备

1. 打开浏览器 DevTools → Application → Local Storage → 清空 `huwuyou_store_v1` 和 `huwuyou_patients`
2. 刷新页面
3. 打开 Console，确保无红色报错

## 首页与入口（访客 + 登录）

- [ ] 1. 冷启动 → 默认进入访客患者端首页（手机壳形态）
- [ ] 2. 首页区块顺序：Banner 区 → 四服务 2×2 网格（诊前咨询/代办服务/特需服务/特色介绍）→ 人工下单 + AI智能下单双横幅 → 热门医院区 → 底部"登录后享受更多服务"引导卡
- [ ] 3. 点击"登录"→ 角色选择页 → "我是患者" → "一键演示登录" → 进入首页（已登录态，出现 AI 浮球 + 通知铃铛）
- [ ] 4. 访客点击"人工下单"横幅 / "立即预约"按钮 / 订单详情 → 弹出登录拦截弹窗 → "去登录"跳角色选择页

## 二级目录与流程页

- [ ] 5. 点击"诊前咨询"服务卡 → 二级目录页（就诊咨询 / 代办咨询），**子卡不显示任何价格**
- [ ] 6. 代办服务、特色介绍二级目录同样无价格字样
- [ ] 7. 点击"特需服务"→ 二级目录有 **3 个子项**：就诊预约 / 预约车辆 / 轮椅助行
- [ ] 8. 点击"就诊预约"→ **直接进入"我的需求"表单**，服务类型预选"半程陪诊"（可修改）
- [ ] 9. 点击其他子项（如"就诊咨询"）→ 流程步骤页：标题为"就诊咨询 · 操作流程"，正文为统一 3 阶段 7 步（服务前：电话咨询/解答问题/合理配置；服务中：提前预备/安全到达/按需服务；服务后：服务记录），步骤编号 1-7 连续，注意事项 4 条保留
- [ ] 10. 流程页底部"立即预约"→ 直接进入"我的需求"表单，按入口预选服务类型
- [ ] 11. 各级返回：二级目录 → 返回首页；流程页 → 返回二级目录；表单 → 返回上一级（逐级正确）

## 统一需求表单（我的需求）

- [ ] 12. 首页"人工下单"横幅 → 直接进入"我的需求"表单（无中间页面），服务类型预选"半程陪诊"
- [ ] 13. 表单顶部有**返回按钮**，点击逐级返回
- [ ] 14. "就诊人"卡为**可编辑**字段：姓名/性别/年龄/联系电话/病史/过敏史/用药/行动能力/紧急联系人/联系人电话，默认回填演示患者信息
- [ ] 15. 医院下拉可选全部在库医院 + "列表里没有？申请新医院"链接
- [ ] 16. 服务类型 4 按钮可切换（半程陪诊/全程陪诊/代办跑腿/陪同复诊），费用确认卡价格联动
- [ ] 17. 修改表单字段 → 打开 AI 面板对话（如"下周二去中山医院看心内科"）→ AI 确认卡与表单数据共享同一草稿（AI 填的信息在表单中可见，反之亦然）
- [ ] 18. 提交校验：姓名留空 / 年龄 0 或 200 / 手机号错误 → toast 拦截；补齐后勾选同意 → 提交成功 → 跳转订单 Tab
- [ ] 19. 提交后再次打开表单：患者档案字段保留，医院/科室/日期/备注等订单字段已清空
