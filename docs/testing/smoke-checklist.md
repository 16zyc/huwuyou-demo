# 人工冒烟测试清单

> Phase 0 基线版本（2026-08-09）
> 每次代码变更后必跑，预计 20 分钟/轮

## 准备

1. 打开浏览器 DevTools → Application → Local Storage → 清空 `huwuyou_store_v1` 和 `huwuyou_patients`
2. 刷新页面
3. 打开 Console，确保无红色报错

## 患者端主链路（访客 + 登录）

- [ ] 1. 冷启动 → 默认进入访客患者端首页（手机壳形态）
- [ ] 2. 首页显示：Banner 区、"AI智能下单"横幅、四服务 2×2 网格（诊前咨询/代办服务/特需服务/特色介绍）、热门医院区、底部"登录后享受更多服务"引导卡
- [ ] 3. 点击"登录"→ 角色选择页 → "我是患者" → "一键演示登录" → 进入首页（已登录态，出现 AI 浮球 + 通知铃铛）
- [ ] 4. 点击"诊前咨询"服务卡 → 进入二级目录页（就诊咨询 ¥128 / 代办咨询 ¥158）
- [ ] 5. 点击"就诊咨询"→ 流程步骤页（6 步 + 注意事项 + "立即预约"按钮）
- [ ] 6. 点击"立即预约"→ 预约表单（患者信息区 + 就医信息区 + 时间范围选择 + "提交预约"按钮）
- [ ] 7. 填写表单（姓名/年龄/科室必填）→ 点击"提交预约"→ toast 提示 → 自动跳转到订单 Tab
- [ ] 8. 订单 Tab 显示新订单（带状态徽章）
- [ ] 9. "我的"Tab 显示用户信息和统计数据
- [ ] 10. 退出登录 → 回到访客首页

## 管理端主链路

- [ ] 11. 角色选择页 → "我是管理员" → "一键演示登录" → 后台布局完整
- [ ] 12. 左侧菜单 9 项完整（工作台/服务跟踪/服务收费/患者档案/需求处理/陪诊师管理/医院审批与资料/评价反馈/系统设置）
- [ ] 13. 工作台显示 KPI 卡片和待处理/服务中列表
- [ ] 14. 需求处理页 → 可筛选状态 → 点击"处理"→ 弹窗显示需求详情 + 推荐陪诊师
- [ ] 15. 选择陪诊师 → toast 提示 → 需求状态变为"已分配"
- [ ] 16. 服务跟踪 → 看到已分配订单 → 点击"详情"→ 可开始服务 → 可完成服务 → 自动弹出报告编辑器
- [ ] 17. 服务收费页 → 修改价格 → 保存 → 变更记录出现
- [ ] 18. 系统设置 → "重置演示数据"→ 确认 → 页面刷新，数据恢复

## AI 下单流程

- [ ] 19. 已登录患者端 → 点击 AI 浮球 → AI 面板打开
- [ ] 20. 输入"下周二去协和看心内科"→ AI 回复确认卡 → 点击"信息正确"→ 依次通过身份证/报告/确认 → 提交成功

## 边界测试

- [ ] 21. 访客点击 AI 下单 / 立即预约 / 订单详情 → 弹出登录拦截弹窗 → "去登录"跳角色选择页
- [ ] 22. 页面刷新后数据仍在（localStorage 持久化正常）
- [ ] 23. 375px 视口：首页 2×2 网格不溢出、Tab 栏可点、表单不横向滚动
- [ ] 24. Console 无 TypeError（特别注意"地址管理"点击不报错）
